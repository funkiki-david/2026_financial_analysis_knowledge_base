# Citation Rules

## Principles

- 重要结论尽量附带来源。
- 尽量记录原始发布日期和访问日期。
- 区分一手资料和二手资料。
- 不把未验证的推测写成事实。

## Minimum Citation Format

- Source name
- Link or file path
- Date published
- Date accessed
- Relevant fact used

## Example

| Source | Published | Accessed | Fact used |
|---|---|---|---|
| Company earnings release | 2026-08-01 | 2026-08-06 | Revenue growth guidance |
