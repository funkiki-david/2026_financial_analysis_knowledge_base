# GitHub 股票分析研究筛选清单

- 文档日期：2026-08-06
- 适用范围：股票研究、公司研究、宏观补充、资料收集、知识库入库
- 目标：先筛出值得长期接入的工具与资料源，而不是一次性装太多

## 使用原则

1. 一手资料优先于二手整理。
2. 免费且稳定的公开源先接入。
3. 只有在明显提升效率或覆盖范围时，才引入付费平台。
4. `API` 只在需要自动化抓取、批量处理、结构化更新时才是必需项。
5. 对没有在官方页面明确写出公开 API 的平台，本文会标记为“未见公开 API（基于当前检索推断）”。

## 一、可安装的 Skills 和 MCP

这一部分不是“金融数据源”本身，而是为了让股票研究工作流更顺。

### 1. 当前已可直接使用，优先保留

| Skill / MCP | 用途 | 是否建议保留 | 说明 |
|---|---|---|---|
| `github:github` / GitHub MCP | 版本管理、研究文档归档、Issue 跟踪 | 是 | 这是当前知识库的长期主仓库 |

| `gmail:gmail` | 接收 IR 邮件、研究订阅 | 可选 | 如果你后面会订阅公司或研究邮件，价值会提高 |

| `Stripe` / `PostHog` / `Sentry` | 偏产品或工程运营，不是当前重点 |

## 二、金融数据平台

### 优先级结论

- 第一梯队：`Alpha Vantage`、`FMP`、`Polygon`、`Koyfin`
- 第二梯队：`Nasdaq Data Link`、`FinanceCharts`
- 如果只是先做研究，不做高频自动化：先用 `Koyfin + Alpha Vantage/FMP + 官方资料源`

| 平台 | 主要用途 | 免费 / 付费 | 是否需要 API | 当前判断 |
|---|---|---|---|---|
| Alpha Vantage | 股票、ETF、宏观指标、基础财务数据 | 免费 + 付费升级 | 自动化时需要 API | 很适合起步 |
| Financial Modeling Prep (FMP) | 财务报表、关键指标、价格、新闻、基础面 | 免费层 + 付费层 | 自动化时需要 API | 对公司研究非常实用 |
| Polygon / Massive | 美股价格、聚合、实时市场数据 | 免费入门 + 付费 | 自动化时需要 API | 更偏行情与量化接口 |
| Nasdaq Data Link | 数据集型平台，适合宏观、另类、历史库 | 既有免费也有付费数据集 | 不一定，但自动化常用 API | 适合后期扩展 |
| Koyfin | 图表、市场面板、可视化研究 | 免费层 + 付费层 | 未见公开 API（基于当前检索推断） | 很适合人工研究 |
| FinanceCharts | 免费图表和基础财务查看 | 免费 | 未见公开 API（基于当前检索推断） | 可作为补充 |

### 平台细化判断

#### Alpha Vantage

- 官方信息：提供免费股票 API，也提供付费 Premium Key。
- 适合：快速接入价格、技术指标、部分宏观与基础财务数据。
- 是否推荐：推荐。
- 最适合阶段：知识库早期自动化。

#### FMP

- 官方信息：有免费 API Key，免费层每天调用数有限，也有更高层级付费计划。
- 适合：公司财务、关键指标、历史价格、公司资料。
- 是否推荐：强烈推荐。
- 最适合阶段：公司研究开始成体系之后。

#### Polygon / Massive

- 官方信息：有免费入门方案，也有更高等级股票计划。
- 适合：更规范的市场数据接口、历史与实时价格。
- 是否推荐：如果你要做更强自动化，推荐；如果只是研究入门，可晚一点再上。

#### Nasdaq Data Link

- 官方信息：平台包含免费和付费数据集。
- 适合：扩展型数据需求，尤其是行业、历史、非标准数据集。
- 是否推荐：中高。
- 更像“数据集市场”，不是只做公司基本面。

#### Koyfin

- 官方信息：有 `Free`、`Plus`、`Premium` 等分层。
- 适合：人工研究、看板、图表、市场与宏观联动观察。
- API 状态：官方定价与产品页未看到公开开发者 API 入口；这里按“未见公开 API”处理。
- 是否推荐：非常推荐作为人工研究前端。

#### FinanceCharts

- 官方信息：官网标注 `100% FREE`。
- 适合：快速看图、看基础财务和历史走势。
- API 状态：当前官方页面检索未见公开 API。
- 是否推荐：作为免费补充工具不错，但不建议当唯一主平台。

## 三、公司与监管资料源

这一类应当作为股票研究的第一优先级。

| 来源 | 主要用途 | 免费 / 付费 | 是否需要 API | 当前判断 |
|---|---|---|---|---|
| SEC EDGAR | 10-K、10-Q、8-K、DEF 14A、13D/13F 等 | 免费 | 不需要；自动化可用 API | 必须优先 |
| 公司 Investor Relations 页面 | 财报公告、电话会材料、演示稿、治理信息 | 免费 | 通常不需要 API | 必须优先 |
| 公司年报 / 季报 PDF | 正式财务披露 | 免费 | 不需要 | 必须优先 |
| Proxy / 股东大会资料 | 管理层、激励、治理结构 | 免费 | 不需要 | 高优先级 |
| Nasdaq Earnings Calendar | 财报日历 | 免费网页 | 不需要 | 补充工具 |

### 实操建议

- 先看 `SEC EDGAR`
- 再看公司 `IR`
- 最后再看平台整理版

原因：平台整理版快，但一手资料才是正式证据。

## 五、新闻与研究资料源

这一类用于补充叙事、观点、事件追踪，不应替代一手资料。

| 来源 | 主要用途 | 免费 / 付费 | 是否需要 API | 当前判断 |
|---|---|---|---|---|
| Reuters | 快速新闻、突发、公司与宏观事件 | 部分免费，专业产品通常付费 | 当前未以公开股票研究 API 为主 | 高质量新闻源 |
| Morningstar | 股票 / 基金研究、评级、工具 | 免费内容 + 付费产品 | 可推断有商业数据接口，但普通用户不必接 API | 高质量研究补充 |
| Seeking Alpha | 公司观点、作者研究、市场讨论 | 免费内容 + Premium / PRO 付费 | 未以公开官方研究 API 为主 | 适合看观点分歧 |
| Koyfin News / 平台新闻面板 | 与市场面板联动 | 平台内分层 | 不以 API 为主 | 研究前端补充 |
| 公司新闻稿 / IR 新闻页 | 一手公告与管理层口径 | 免费 | 不需要 | 应优先于媒体解读 |

### 如何用

- 看新闻：先知道发生了什么
- 回到一手资料：确认事实
- 再用研究平台：比较叙事差异

## 七、当前最推荐的最小可用组合

如果目标是先把 “GitHub 股票分析研究” 做成可用研究系统，而不是一次性买很多工具，我建议从这套最小组合开始：

### 免费主组合

- 一手资料：`SEC EDGAR + 公司 IR`
- 宏观：`FRED + BLS + BEA`
- 公司财务补充：`FMP 免费层` 或 `Alpha Vantage 免费层`
- 人工研究前端：`Koyfin 免费层` 或 `FinanceCharts`
- 知识沉淀：`GitHub + 当前知识库`

### 进入下一阶段再考虑升级

- 如果要批量抓数：升级 `FMP` 或 `Polygon`
- 如果要更强图表与研究体验：升级 `Koyfin`
- 如果要专业研究数据库：再评估 `FactSet` / `Morningstar` 高级产品

## 八、建议的接入顺序

1. 先接 `SEC EDGAR`、公司 IR、FRED、BLS、BEA
2. 再接一个公司数据平台：首选 `FMP`，备选 `Alpha Vantage`
3. 再加一个人工研究前端：首选 `Koyfin`
4. 等研究工作流稳定后，再评估 `Polygon`、`Nasdaq Data Link`、`FactSet`
