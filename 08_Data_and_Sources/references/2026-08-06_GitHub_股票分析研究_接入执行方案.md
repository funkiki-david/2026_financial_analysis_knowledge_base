# GitHub 股票分析研究接入执行方案

- 文档日期：2026-08-06
- 关联文档：`2026-08-06_GitHub_股票分析研究_筛选清单.md`
- 目标：把筛选结果变成可以执行的接入顺序与落库规则

## 一、执行目标

这一阶段不追求一次性把所有平台都接上，而是先建立一套稳定、低风险、能持续积累的研究资料输入系统。

成功标准：

1. 一手公司资料可以稳定进入知识库
2. 核心宏观数据源已经明确并可调用
3. 至少一个公司数据平台开始用于辅助研究
4. 所有新资料都知道该放到哪里
5. 暂时不引入过重、过贵、过复杂的系统

## 二、第一阶段接入范围

### 必做

- SEC EDGAR
- 公司 Investor Relations 页面
- FRED
- BLS
- BEA
- FMP 或 Alpha Vantage 二选一，优先 FMP
- Koyfin 免费层或 FinanceCharts 作为人工研究前端

### 暂缓

- Polygon
- Nasdaq Data Link
- FactSet
- Morningstar 高级产品
- Seeking Alpha PRO
- OECD / IMF / World Bank 的系统化自动接入

原因不是它们没价值，而是当前阶段最重要的是把主干流程跑顺。

## 三、资料分类与保存规则

### 1. 公司与监管资料

保存位置：

- 原始文件或链接记录：`08_Data_and_Sources/references/`
- 正式公司研究：`04_Company_Notes/Active_Research/<Ticker>/`

推荐做法：

1. 先看 `SEC EDGAR`
2. 再看公司 `IR`
3. 下载或记录关键文件
4. 提炼成正式研究笔记

### 2. 宏观资料

保存位置：

- 原始数据说明或链接：`08_Data_and_Sources/references/`
- 整理后的宏观框架或结论：`03_Research_Frameworks/Macro_Research/`
- 每日或每周复盘引用：`05_Market_Reviews/`

### 3. 平台型数据

保存位置：

- 原始导出数据：`08_Data_and_Sources/raw_data/`
- 清洗后的结构化表：`08_Data_and_Sources/processed_data/`
- 从数据得出的正式研究结论：对应正式目录，不直接停留在原始数据区

## 四、第一阶段具体执行顺序

## Step 1: 建立公司资料输入主线

目标：确保每次研究公司时，都知道先去哪里拿一手资料。

执行内容：

- 用 `SEC EDGAR` 查 10-K / 10-Q / 8-K
- 用公司 `IR` 查财报新闻稿、电话会纪要、投资者演示
- 把关键入口保存到 `08_Data_and_Sources/references/`

建议先做 2 个样本公司：

- NVDA
- AAPL

原因：

- 两者资料公开、结构清晰、研究价值高

## Step 2: 建立宏观资料主线

目标：让市场复盘不只是看新闻，而是能回到核心宏观序列。

执行内容：

- FRED：利率、信用利差、失业、通胀、收益率曲线
- BLS：就业、CPI、PPI
- BEA：GDP、消费、行业增加值

建议先建立一份“核心宏观序列清单”：

- 联邦基金利率
- 10Y 美债收益率
- CPI
- Core CPI
- Nonfarm Payrolls
- Unemployment Rate
- Retail Sales

## Step 3: 选择一个公司数据平台

目标：不要同时接多个同类平台。

建议：

- 首选：FMP
- 备选：Alpha Vantage

原因：

- FMP 对公司研究更直接，财务报表、关键指标、公司资料覆盖更贴近当前任务
- Alpha Vantage 更适合轻量起步和通用接口

第一阶段决策：

- 默认先用 FMP
- 后面如果更偏价格或更偏实时，再考虑 Polygon

## Step 4: 建立人工研究前端

目标：让日常看盘、看公司、看图表更顺畅。

建议：

- 首选：Koyfin 免费层
- 备选：FinanceCharts

用途：

- 快速切换公司、指数、板块、宏观序列
- 人工形成研究线索
- 不直接替代正式知识沉淀

## 五、哪些先手动，哪些后面自动化

### 先手动

- 打开 SEC / IR / 宏观官网核对来源
- 判断哪些资料值得保存
- 把原始资料归类到正确目录
- 从资料提炼成正式研究结论

### 第二阶段再自动化

- 从 API 拉取时间序列
- 批量抓取基础财务指标
- 自动生成资料索引
- 自动更新观察名单
- 自动生成每周资料汇总

### 暂时不要自动化

- 自动生成投资结论
- 自动覆盖历史研究文件
- 自动用新闻替代一手披露
- 自动引入大量未验证数字

## 七、当前最推荐的落地组合

如果只允许先做一个最小但高价值的落地组合，那么就是：

### 公司研究主线

- SEC EDGAR
- 公司 IR
- FMP

### 宏观主线

- FRED
- BLS
- BEA

### 人工研究前端

- Koyfin

### 知识沉淀

- 当前 GitHub 知识库

## 八、这一阶段完成后的下一阶段

当上面的主线跑顺以后，再进入下一阶段：

1. 建立核心宏观序列清单
2. 建立 2 家样本公司的资料入口与正式研究页
3. 建立观察名单总表
4. 开始考虑 API 自动抓取
5. 再评估是否需要升级到 Polygon、Nasdaq Data Link 或更高阶平台

## 九、当前结论

截至 2026-08-06，最合理的推进方式不是“把所有工具都装上”，而是：

- 先把一手资料主线建立起来
- 再加一个公司数据平台
- 再加一个人工研究前端
- 最后才做自动化

这条顺序更稳，也更符合长期知识库建设。
