# Data Dictionary

## Purpose

统一记录本知识库常见数据项的含义，减少以后不同笔记之间的口径漂移。

## Core Fields

| Field | Meaning |
|---|---|
| Revenue growth | 收入同比或环比增长 |
| Gross margin | 毛利率 |
| Operating margin | 营业利润率 |
| Free cash flow | 自由现金流 |
| Net debt | 净债务 |
| Valuation multiple | 估值倍数，如 PE、EV/EBITDA、PS |

## Rule

如果某篇研究笔记使用了特殊定义，必须在文中额外注明。
