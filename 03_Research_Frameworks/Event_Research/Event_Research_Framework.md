# Event Research Framework

## Purpose

为财报、产品发布、监管事件、并购、政策变化等离散事件建立统一研究方法。

## Core Questions

1. 事件本身是什么？
2. 哪些事实已确认，哪些仍是推测？
3. 这个事件为什么重要？
4. 市场在事件前后主要交易什么？
5. 事件影响是一次性的还是持续性的？

## Standard Flow

### Before the Event

- 市场预期是什么
- 共识在哪里
- 关键敏感点是什么

### During the Event

- 新出现的硬信息是什么
- 是否超预期或低于预期
- 管理层、监管方或市场参与者传递了什么关键信号

### After the Event

- 价格反应如何
- 反应对应的逻辑是什么
- 哪些变化是短期噪音，哪些可能改变中长期判断

## Output Standard

- 事件摘要
- 市场预期
- 实际结果
- 价格反应
- 逻辑判断
- 后续跟踪点
