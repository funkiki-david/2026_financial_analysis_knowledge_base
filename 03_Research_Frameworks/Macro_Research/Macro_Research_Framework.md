# Macro Research Framework

## Purpose

把宏观研究限定在“影响资产价格和研究判断的关键变量”上，避免无边界扩散。

## Core Questions

1. 当前最重要的宏观变量是什么？
2. 哪些变量真的影响市场，哪些只是背景噪音？
3. 当前市场交易的是增长、通胀、流动性还是政策路径？
4. 哪些资产对这些变量最敏感？

## Standard Flow

### 1. Define the Macro Topic

- 增长
- 通胀
- 利率
- 流动性
- 汇率
- 政策

### 2. Identify Key Data Points

- 非农
- CPI / PPI
- GDP
- 零售销售
- PMI / ISM
- 利率决议
- 财政政策变化

### 3. Separate Levels from Direction

- 绝对水平如何
- 边际变化如何
- 市场预期和实际结果差在哪里

### 4. Map Market Impact

- 哪类资产最敏感
- 风格轮动方向
- 板块与因子受益/受损情况

### 5. Build Scenario View

- 基准情景
- 上行情景
- 下行情景

## Output Standard

- 主题定义
- 关键数据与方向
- 市场预期差
- 资产影响
- 观察清单
