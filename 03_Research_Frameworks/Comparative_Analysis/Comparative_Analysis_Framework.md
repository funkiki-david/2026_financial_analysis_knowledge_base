# Comparative Analysis Framework

## Purpose

用于比较多个公司、多个行业观点或多个研究结论，帮助识别相对优势与相对风险。

## Comparison Dimensions

- 业务模式
- 增长质量
- 利润率
- 现金流
- 资本配置
- 估值
- 竞争地位
- 风险暴露

## Method

1. 先定义比较目标。
2. 只选与目标最相关的维度。
3. 区分事实比较和判断比较。
4. 不用单一指标得出整体优劣结论。
5. 输出时明确“哪方面更强、哪方面更弱、为什么”。

## Good Output

- 比较对象
- 比较维度
- 关键差异
- 哪类情景下谁更占优
- 哪些结论仍待验证
