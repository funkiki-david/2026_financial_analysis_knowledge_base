# Operating Rules

## 文件处理原则

- 不直接覆盖已有研究文件。
- 优先通过 `scripts/kb_save.sh` 保存新内容。
- 未确认分类的内容先进入 `90_Inbox/incoming/`。
- 原始外部资料尽量先保留在 `08_Data_and_Sources/`，再提炼到正式研究笔记。
- 重要研究结论尽量同时记录来源、日期、假设、风险与后续验证点。

## 命名建议

- 推荐格式：`YYYY-MM-DD_Title.ext`
- 公司研究建议使用：`04_Company_Notes/Active_Research/<Ticker>/`
- 模板与长期文档尽量用稳定文件名

## Git 规则

- 先在分支上整理，再决定是否合并到主分支。
- 未经确认，不推送、不部署、不删除旧文件。
