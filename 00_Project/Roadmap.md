# Roadmap

## Phase 1: Foundation Setup

- 建立目录结构
- 建立 README 和项目规则
- 建立模板与自动保存脚本
- 建立引用和来源规则

## Phase 2: Learning System

- 开始金融基础笔记
- 开始市场微结构笔记
- 建立术语表
- 建立阅读记录
- 建立问题清单

## Phase 3: Company Research

- 选择少量公司作为研究样本
- 使用统一模板
- 保存原始资料
- 建立假设与跟踪指标
- 定期更新研究记录

## Phase 4: Review System

- 每日市场观察
- 每周研究复盘
- 财报后复盘
- 重大事件后复盘
- 年度研究总结

## Phase 5: AI Workflows

- 创建 Prompt Library
- 标准化资料总结流程
- 标准化财报分析流程
- 标准化公司对比流程
- 建立 AI 输出核对清单

## Phase 6: Safe Automation

只自动化低风险、重复性工作，例如：

- 文件命名
- Markdown 格式统一
- 索引更新
- 来源列表更新
- 待办事项生成
- 定期汇总
