# Directory Map

## Purpose

这个文件用来快速说明每个一级目录应该放什么，不该放什么。

## Top-Level Map

### `00_Project/`

项目规则、导航、路线图、说明文档、变更记录。

### `01_Financial_Foundations/`

金融基础概念、会计、公司金融、估值、风险管理。

### `02_Market_Structure/`

交易所、订单类型、流动性、做市、价格发现、市场参与者行为。

### `03_Research_Frameworks/`

公司、行业、宏观、事件、财报、比较分析的方法论框架。

### `04_Company_Notes/`

观察名单、在研公司、已归档公司研究。

### `05_Market_Reviews/`

日、周、月、年复盘。

### `06_Research_Templates/`

可直接复用的研究模板。

### `07_AI_Workflows/`

提示词、AI 归档流程、自动化想法、操作 SOP。

### `08_Data_and_Sources/`

原始数据、处理后数据、来源规则、数据口径说明。

### `09_Learning_Log/`

问题、错误、反思、学习记录。

### `10_Glossary/`

术语表与常用定义。

### `90_Inbox/`

未分类临时内容的收件区。
