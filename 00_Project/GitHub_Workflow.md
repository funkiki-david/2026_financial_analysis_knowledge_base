# GitHub Workflow

## Purpose

This document explains how the local knowledge base and the GitHub repository should work together.

## Repository

- GitHub repository: `funkiki-david/2026_financial_analysis_knowledge_base`
- Local root: `/Users/davidz/2026 金融分析知识库`
- Default branch: `main`

## Recommended Flow

1. Make changes locally.
2. Review what changed.
3. Commit with a focused message.
4. Push to GitHub.
5. Use issues for research tasks or workflow improvements if useful.

## Branch Naming Suggestions

- `codex/<task-name>`
- `notes/<topic>`
- `workflow/<improvement>`

## Good Commit Message Examples

- `docs: add company research framework`
- `workflow: improve inbox promotion script`
- `notes: add NVDA initial research sample`

## Important Safety Rule

Do not delete or rewrite historical notes unless the change is deliberate and the history remains recoverable through Git.
