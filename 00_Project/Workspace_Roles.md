# Workspace Roles

## Core Principle

ChatGPT Project 是研究工作台，GitHub 是长期知识仓库。

## ChatGPT Project Is Best For

- 讨论
- 学习
- 提问
- 头脑风暴
- 分析资料
- 形成初步框架
- 延续上下文

## GitHub Repository Is Best For

- 正式保存知识
- 文件管理
- 版本控制
- 任务追踪
- 模板维护
- 长期归档
- 与 Codex Desktop 协作

## Recommended Workflow

1. 在 ChatGPT Project 中讨论研究主题、方法和问题。
2. 把稳定结论整理成 Markdown。
3. 将 Markdown 保存到知识库与 GitHub 仓库。
4. 使用 Issues 记录待研究问题。
5. 使用目录、模板和框架文件维持长期一致性。
