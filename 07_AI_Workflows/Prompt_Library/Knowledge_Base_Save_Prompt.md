# Knowledge Base Save Prompt

## Use Case

当你希望我把一段内容直接整理并落到本地知识库时，可以复用下面这个提示方式。

## Prompt

```text
请把下面内容整理成适合保存到“2026 金融分析知识库”的文档。

要求：
1. 先判断它属于哪个目录。
2. 如果信息不足，先进入 Inbox。
3. 提炼标题、日期、来源、关键事实、主要结论、风险和下一步。
4. 用规范 Markdown 输出。
5. 保存时不要覆盖已有文件。

内容：
[粘贴原文]
```

## Best For

- 临时研究片段
- 新闻摘要
- 聊天整理结果
- 公司初步观察
